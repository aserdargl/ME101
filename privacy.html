LectureNotes Drive — Privacy

LectureNotes is a teaching portal operated by Ahmet Serdar Güldibi. The website remains on GitHub Pages. The instructor can connect a Google Drive account to store course files and independent backups.

Google Drive access

The application requests the drive.file permission. This permits access to files created by this application or specifically selected for it. It does not request access to the entire Drive account, Gmail, contacts or other unrelated files.

Course files selected for publication can be displayed through the course portal. Backup files remain private in the instructor’s Drive. Student rosters, passwords and enrollment records are not included in course backups.

Credentials and data

Google refresh credentials are stored in server-only configuration and are not published to GitHub or made available to students. The portal uses access credentials only to perform the requested file storage, verification, display and backup operations. Google user data is not sold, used for advertising or used to train generalized artificial intelligence models.

Retention and control

Existing course notes and older backups are preserved. The instructor controls retention through Google Drive and can revoke application access through Google Account connections. Revoking access stops future Drive operations; it does not delete stored files.

No credit card, Google Cloud billing account, paid plan or pay-as-you-go upgrade is required by this integration. Existing Google Drive storage and service quotas apply.
