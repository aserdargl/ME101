# Automatically synchronized weekly files

`manifest.json` and `files/` are managed by the local Week Sync tool. Files removed
from the selected Drive folder are removed here on the next successful sync.
Existing lectures in `data/`, student records, ratings and settings are unaffected.

Source names: `1.Week.pdf`, `2.Week.html`, `3.Week.pptx`, or folders such as
`1.Week/Notes.pdf`. PDFs and standalone HTML open inside the site. PPTX files are
available for download; upload a PDF copy for in-browser slide viewing.
